21 CFR Part 11 compliance

The Certos framework meets the requirements of FDA Part 11, which requires the device manufacturer to implement very secure software and controls: audits, system validations, audit trails, electronic signatures and documentation for the software and systems that process the electronic data.

  • 21 CFR Part 11 compliance
  • Encrypted databases
  • Secure network protocols (HTTPS, FTPS)
  • System test reports according to FDA
  • Secure electronic records
  • Audit trail
  • Verified accurate and complete data transfer
  • Validated data integrity
  • Device-specific encrypted data backups on external servers
  • Limitation of access to authorised individuals
  • Password expiration and reset
  • Multilevel user roles
  • Forced complex passwords
  • Password history
  • User blocking techniques
  • PDF signatures with single and double opt-in
  • Verification of individuals by RFID, barcode or password
  • Secure timestamps
  • Printouts according to GMP/GLP requirements
  • Electronic signature

Machine-learning based analytics

The AI part of the CertosCloud backend is written in Python, so the applications can run on different machine learning algorithms. The best-performing ones are linear regression, logistic regression, decision tree, SVM, naive Bayes, kNN, k-means and random forest.

For predictive maintenance based on sensor data from internal components of laboratory equipment, the Certos team found that the random forest algorithm shows the best performance yet.

Cloud or on-premise

The cloud software can be installed on a local server using Docker. Installation takes one minute, and no internet connection is required.

Alternatively the online cloud can be used with no installation at all, available on a custom domain of your choosing.

Remote access via tablet and smartphone

Option 1 — remote control by humans. The framework supports TeamViewer QuickSupport integration for remote training, configuration and service, with screen sharing from desktop or mobile. The CertosCloud web interface also allows users to authenticate, configure the device remotely and browse its data.

Option 2 — automated remote control by third-party software. CertosCloud comes with a REST API plus FTP and HTTP/2 protocols, so ERP systems or a LIMS can send and receive real-time and historical data from the laboratory equipment.

Controlling multiple devices

Certos can control multiple devices at the same time via CertosCloud.

Connectivity with external devices

Certos Cloud comes with a standard communication protocol based on HTTP/2, including Swagger UI documentation, so connecting the laboratory device to a LIMS or other third-party software is easy. New protocols such as AniML and SiLA2 are also supported, and any new communication standard arriving on the market will be supported via a software update.
