Security & 21 CFR Part 11

The Certos HMI framework meets the requirements of FDA Part 11. It requires that the device manufacturer implements very secure software and controls, including audits, system validations, audit trails, electronic signatures and documentation for software and systems involved in processing the electronic data.

  • 21 CFR Part 11 compliance
  • Encrypted databases
  • Secure network protocols (HTTPS, FTPS)
  • System test reports according to FDA
  • Secure electronic records
  • Audit trail
  • Verified accurate and complete data transfer
  • Validated data integrity
  • Device-specific encrypted data backups on external servers
  • Limitation of access to authorised individuals
  • Password expiration and reset
  • Multilevel user roles
  • Forced complex passwords
  • Password history
  • User blocking techniques
  • PDF signatures with single and double opt-in
  • Verification of individuals by RFID, barcode or password
  • Secure timestamps
  • Printouts according to GMP/GLP requirements
  • Electronic signature
Connecting an existing device

Maybe you, as a laboratory device manufacturer, are asking: “How do I build a touchscreen with the Certos HMI framework into my laboratory device?” The framework comes with configurable device drivers. If an existing device has any communication interface — a serial port, RS232C, UART, LAN, Bluetooth, WiFi, IO pins, RS485 — it can be connected.

In some cases, libraries for communication with the laboratory equipment are already available. The framework can include .dll files, C# libraries, Java libraries, C libraries, .jar files and many more.

Predictive maintenance & process mining

Predictive maintenance. The predictive maintenance mechanism is built from classification models that categorise the health condition of a device’s components. With a dataset of on average 35,000 device records, failure prediction accuracy reaches up to 83%. Source: Classification model for predictive maintenance of small steam sterilizers.

Process mining. The audit trail generated by the framework can be analysed in CertosCloud to detect standard operating procedures and compare them with the specification.

Custom applications and peripherals

The Certos Framework is a general platform for different kinds of laboratory devices. Every manufacturer can add custom applications relevant to their specific device only. Every custom application is separated from other parts of the software to ensure a secure, encapsulated software design.

The framework supports office printers, label printers, protocol printers, RFID card scanners, QR code scanners, barcode scanners, and third-party devices such as balances, scales, liquid handling solutions, mixers and sensors including pH meters, temperature sensors, cameras and microphones.
