Technology

Technology of the HMI framework

More than 200 drivers for connecting to third-party laboratory devices directly, with a state-of-the-art communication standard for device-to-device communication.

Multi-protocol communication

Certos allows simultaneous support of multiple communication protocols and standards, or proprietary protocols. With dedicated configurable coding systems, Certos supports flexible mapping between local and external codes and identifiers.

What CertosCloud integration means

The Certos Framework is designed to be fully compatible with the CertosCloud device management platform. CertosCloud is a fully managed, scalable and fault-tolerant laboratory device management platform.

Certos Cloud serves as an FDA-compliant automated backup and restore solution and as a remote device management platform. The platform supports up to 500,000 devices and users and up to 1,000 TB of storage.

Security in connection and operation

Certos promises security in connection and operation to provide protection in data transfer, uploading, storage and more. We continuously maintain and update the frameworks to ensure that connected laboratory equipment remains safe as well.

Ready-to-use preference utilities

The HMI framework comes with rich preference utilities that are completely ready to use, including a default GUI, which allows manufacturers full customisation over appearance and functionality.

The preference utilities make it easy to create Part 11 compliant application settings — such as changing system time, setting up maintenance reminders, and user management settings such as user roles.

Connecting to your existing controller

Certos has deep expertise in connecting a tablet PC to the typical microprocessor-based controller of a laboratory device. We have designed our communication logic with a great deal of experience in connecting existing devices to a new controller.

Cross-platform by design

Certos is a cross-platform application and HMI framework. It includes a cross-platform class library, integrated development tools and a cross-platform integrated development environment — enabling developers to quickly and efficiently build industrial, scientific or web-enabled applications.

User interface components

Your laboratory device user interface is everything the user can see and interact with. Certos provides a wide variety of pre-built UI components, such as structured layout objects and UI controls, plus modules for special interfaces such as dialogues, notifications and menus.

Built-in user support

The framework has a range of functions built in for user support: on-screen live user support, on-screen instruction videos, and the option to schedule live calls on the machine using TeamViewer.

Automatic background backups

Certos Framework backs up all data in the background. No manual work is required. The backup service ensures smooth operation and avoids any loss of data, results and lab equipment progress via cloud-integrated functions — in a separate system from the primary data.

Machine learning built in

Certos is built with artificial intelligence based on machine learning to generate predictive maintenance, repair and many other predictive analyses.

Multi-user on one device

Certos allows equipment manufacturers and end users to have multiple users on the same device or HMI, working like separate computer accounts. This ensures not only efficiency in collaboration but also the safety and security of each user.

Extensibility and peripherals

The HMI framework enables developers and users to extend the software by adding more applications, and supports a wide range of office printers, scanners and essential equipment in a lab setting.

Cloud

Superior cloud solution

Full cloud specification

Built on the latest technologies

The Certos white-label cloud is built using a current stack: a React front end, a Java back end and your choice of PostgreSQL, MongoDB or Cassandra.

Extend with prebuilt widgets

Extending the features of the Certos Cloud works by simply adding prebuilt widgets. And if need be, you can easily build your own widgets and run them on top of the platform.

Top-ranking security qualifications

CertosCloud is certified with top-ranking security qualifications and protocols, and can guarantee the highest level of secured connection.

Machine learning via the cloud

Certos Cloud enables the HMI to use machine learning via a cloud connection to perform predictive maintenance, analytics and many other functions.

On-premise, if your customers prefer it

Some of your customers dislike using cloud services. No problem. CertosCloud can also run on-premise with a one-click installation — we even offer pre-approved hardware.

Access from any smartphone or tablet

With CertosCloud you can safely access your lab devices from any smartphone or tablet, control multiple devices at the same time, and connect external devices including other lab equipment, printers and scanners.
